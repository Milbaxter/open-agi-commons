# Project decisions

The initial repository owner is `Milbaxter`.
The owner maintains this overview until more maintainers are named publicly.

Maintainers confirm task claims, review evidence, set credit labels, and merge changes.
Contributors can propose scope, metric, and policy changes through issues and pull requests.
Record the reason for a substantial decision in its issue or PR.

The leaderboard does not control merge decisions.
Accept a change for its value, evidence, and fit with the mission.
Reject score inflation, duplicate work, and unsupported claims.

For an experiment, use a verifier other than its author.
Before component code receives outside contributions, configure branch rules,
required checks, and review requirements for that repo.
This document states project policy. It does not claim those GitHub rules are already enabled.

Treat others with respect. Discuss the work and evidence.
Report credit errors or process problems through an issue.

# Roadmap

## Stage 0: overview foundation — available

- Public mission and full stack map.
- Registry with 17 planned workstreams.
- Agent instructions, task files, and contribution templates.
- Repo checks and a generated merged-PR leaderboard.
- Starter issues for useful planning work.

## Stage 1: prepare the first experiments — next

Map existing evaluation projects. Select reusable tools before building new ones.
Write fixed experiment contracts for inference and memory.
Choose the first open model, license, reference agent, and task families.
State laptop and GPU requirements for each proposed task.

Pass condition: a reviewer can select a baseline and reproduce its setup.

## Stage 2: open the first component repos — planned

Create evaluation, inference, and memory repos when their scopes are clear.
Give each repo a maintainer role, checked baseline, and ready work packets.
Add real URLs to the registry. Pin tested commits after integration checks pass.

Pass condition: a new contributor can complete one task through a supported coding tool.

## Stage 3: prove the contribution loop — planned

Complete a contribution with Codex and one with Claude Code or another tool.
Repeat both results independently. Merge useful changes and publish their evidence.
Measure resource use and human review time.

Pass condition: donated agent work produces repeatable, useful improvements.

## Stage 4: extend the stack — planned

Open more component repos as their baselines and review capacity become ready.
Add cross-repo integration tests and tested commit records.
Evaluate a local task runner and scheduled maintainer work after the manual process works.

Pass condition: more accepted work per total budget, with reliable checks.

These stages have no fixed dates. Evidence and review capacity set the pace.
